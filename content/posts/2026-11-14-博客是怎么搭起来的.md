这篇演示写文章会用到的所有写法：标题、列表、表格、代码块、引用。

## 文字与强调

一行正文大约三十八个汉字。强调用**粗体**，行内代码写成 `python3 build.py`，这是整页唯一用等宽的地方。

> 引用是左边一条竖线，文字退成次要颜色。适合放结论。

## 列表与表格

1. 新建一个 `.md` 文件放进 `content/posts/`
2. 头部写 `title` / `date` / `tags` / `summary`
3. 跑 `python3 build.py`

| 想改什么 | 改哪个文件 |
| --- | --- |
| 名字、简介、导航、强调色 | `site.json` |
| 页面排布、字号、间距 | `assets/site.css` |
| 一整套外观规则 | `assets/endfield.css` |
| 只改某一篇的排版 | 那篇 `.md` 里加一段 `<style>` |

## 代码块

```python
python3 build.py      # 生成 dist/
python3 -m http.server -d dist 8080   # 本地看效果
```

数字都是真的：篇数、字数、最近更新，都是脚本现算的。所以别在界面上手写统计，改了内容它们会自己变。
